# Шпаргалка [Демонстрационный экзамен] — ВЯП 1С
## Контекстные операторы
- `ЭтотОбъект` — оператор, возвращающий текущий модуль.

## Типы данных
- `ДиалогВыбораФайла([Режим работы])` — тип данных, представляющий собою диалог открытия файла;

### Вспомогательные объекты типа данных `ДиалогВыбораФайла`
- `РежимДиалогаВыбораФайла` — объект, представляющий собою режимы диалога выбора файла.

#### Дочерние идентификаторы объекта `РежимДиалогаВыбораФайла`
- "`.Открытие`" — идентификатор, указывающий режим выбора файла как "Открытие".

##### Общий синтаксис
```1C
[объект] = Новый ДиалогВыбораФайла(РежимДиалогаВыбораФайла.Открытие)
```

### Дочерние идентификаторы типа данных `ДиалогВыбораФайла`
- "`.МножественныйВыбор`" — идентификатор, отвечающий за возможность множественного выбора файлов;

#### Синтаксис
```1C
[диалог выбора файла].МножественныйВыбор = [Истина/Ложь]
```
- - -
- "`.Фильтр`" — идентификатор, отвечающий за возможность фильтрации форматов файлов при выборе.

#### Синтаксис
```1C
[диалог выбора файла].Фильтр = "[Описание файла] (*.[формат]) | *.[формат]"
```

### Дочерние методы типа данных `ДиалогВыбораФайла`
- "`.Показать([Описание оповещения])`" — метод, вызывающий диалоговое окно выбора файла и возвращающий объект (`Массив`) выбранных файлов.

#### Вспомогательные типы данных метода "`.Показать()`"
- `ОписаниеОповещения` — тип данных, представляющий собою описание оповещения в процессе выбора файла.

##### Общий синтаксис
```1C
[диалог выбора файла].Показать(Новый ОписаниеОповещения("[Процедура, вызываемая после успешного импорта файла]",
    [Текущий модуль, по которому выполняется поиск вызываемой процедуры], [Дополнительный параметр, передаваемый в процедуру]))
```
- - -
- `ТабличныйДокумент` — тип данных, представляющий собою табличный документ.

### Дочерние идентификаторы типа данных `ТабличныйДокумент`
- "`.ВысотаТаблицы`" — идентификатор, возвращающий числовой литерал — высоту таблицы.

#### Синтаксис
```1C
[объект] = [табличный документ].ВысотаТаблицы
```
- - -
### Дочерние методы типа данных `ТабличныйДокумент`
- "`.Прочитать([путь к файлу])`" — метод, выполняющий чтение файла табличного документа.

#### Синтаксис
```1C
[табличный документ].Прочитать([путь к файлу]);
```
- - -
- "`.Область([строка], [столбец])`" — метод, возвращающий объект — ячейку в заданной области таблицы.

#### Синтаксис
```1C
[объект] = [табличный документ].Область([строка], [столбец])
```

#### Дочерние идентификаторы метода "`.Область()`"
- "`.Текст`" — идентификатор, возвращающий строковый литерал — значение ячейки.

##### Синтаксис
```1C
[объект] = [ячейка].Текст
```

## Глобальные процедуры и функции
- `ЗначениеЗаполнено([контейнер])` — функция, проверяющая, заполнено ли значение контейнера, и возвращающая булев литерал — Истину (если да) или Ложь (если нет).

### Синтаксис
```1C
[объект] = ЗначениеЗаполнено([контейнер])
```
- - -
- `Дата([дата])` — функция, возвращающая объект — дату.

### Синтаксис
```1C
[объект] = Дата("[день].[месяц].[год] [часы]:[минуты]:[секунды]")
```

### Вспомогательные функции процедуры `Дата()`
- `ТекущаяДата()` — функция, возвращающая объект — значение текущей даты.

#### Синтаксис
```1C
[объект] = ТекущаяДата()
```
- - -
- `НачалоМесяца("[дата]")` — функция, возвращающая объект — дату с переведённым в начало месяцем.

#### Синтаксис
```1C
[объект] = НачалоМесяца("[дата]")
```
- - -
- `ДобавитьМесяц([дата], [количество])` — функция, возвращающая объект — дату с увеличенным месяцем.

#### Синтаксис
```1C
[объект] = ДобавитьМесяц([дата], [количество])
```
- - -
- `ПредопределенноеЗначение("[Перечисление]")` — функция, возвращающая ссылку на реквизит объекта — перечисления.

### Синтаксис
```1C
[объект] = ПредопределенноеЗначение("[Перечисление].[Дочерний объект].[Реквизит]")
```
- - -
- `ОткрытьФорму("[Объект]", <Структура>)` — процедура, выполняющая вызов формы.

### Синтаксис
```1C
ОткрытьФорму("[Объект].[Дочерний объект]...", Новый Структура("[Параметр № 1]", [значение]))
```

```1C

Процедура [Импорт данных]НаСервере([пути к файлам], Неважно) Экспорт
    // Условные конструкции:
	Если [пути к файлам] <> Неопределено Тогда
		[ссылка на файл] = <пути к файлам>[0];

        // Вызов процедур:

	[табличный документ] = Новый ТабличныйДокумент;

    // Циклы:
	Для строка = 2 По [табличный документ].ВысотаТаблицы Цикл
        // Объекты:
		[объект № 1] = [табличный документ].Область(строка, 2).Текст;
		
        // Условные конструкции:
		Если Справочники.[Идентификатор объекта № 1].НайтиПоКоду([объект № 1], Истина).Пустая() Тогда
            // Объекты:
			[новый объект № 1] = Справочники.[Идентификатор объекта № 1].СоздатьЭлемент();

            // Условные конструкции:
			Если Справочники.[Идентификатор объека № 2].НайтиПоНаименованию([объект № 2], Истина).Пустая()  Тогда
                // Объекты:
				[новый объект № 2] = Справочники.[Идентификатор объекта № 2].СоздатьЭлемент();

				[новый объект № 2].Записать();

				Сообщить("Создан новый объект № 2: '" + [новый объект № 2].Наименование + "'.");
			КонецЕсли;
			
            // Объекты:
			[новый объект № 1].[Элемент № 1] = Справочники.[Идентификатор объекта № 2].НайтиПоНаименованию([объект № 2], Истина);
			[объект № 3] = [табличный документ].Область(строка, 3).Текст;
			
            // Условные конструкции:
			Если Справочники.[Идентификатор объекта № 3].НайтиПоНаименованию([объект № 3], Истина).Пустая()  Тогда
				// Объекты:
                [новый объект № 3] = Справочники.[Идентификатор объекта № 3].СоздатьЭлемент();
				[новый объект № 3].Наименование = [объект № 3];
				[новый объект № 3].Записать();
				
                // Вызов процедур:

			КонецЕсли;
			
            // Объекты:
			[новый объект № 1].[Элемент № 2] = Справочники.[Идентификатор объекта № 3].НайтиПоНаименованию([объект № 3], Истина);
			[новый объект № 1].Записать();

			Сообщить("Объект " + [объект № 1] + " уже существует.");
		КонецЕсли;
	КонецЦикла;
```

### Общий синтаксис — форма авторизации (нестандартные реквизиты: Пользователь — СправочникСслка.Пользователи)
```1C
&НаСервере
Функция [Вход]НаСервере() Экспорт
	// Объекты:
	Пользователь = Справочники.Пользователи.НайтиПоНаименованию(Логин, Истина);
	
	// Условные конструкции:
	Если НЕ Пользователь.Пустая() Тогда
		// Объекты:
		активность = Пользователь.Активность;
		
		// Условные конструкции:
		Если активность = Истина Тогда
			Если Пароль = Пользователь.Пароль Тогда
				Если НЕ ЗначениеЗаполнено(Пользователь.ДатаВхода) Тогда
					Возврат Пользователь.Роль;
				ИначеЕсли ТекущаяДата() <= ДобавитьМесяц(Пользователь.ДатаВхода, 1) Тогда
					// Вызов процедур:
					изменениеДанных("КоличествоПопыток", 0);
					изменениеДанных("ДатаВхода", ТекущаяДата());
					
					Возврат Пользователь.Роль;
				Иначе
					// Вызов процедур:
					изменениеДанных("Активность", Ложь);
					
					Возврат Неопределено;
				КонецЕсли;
			Иначе
				// Объекты:
				количествоПопыток = Пользователь.КоличествоПопыток;
				количествоПопыток = количествоПопыток + 1;
				
				// Условные конструкции:
				Если количествоПопыток = 3 Тогда
					// Вызов процедур:
					изменениеДанных("Активность", Ложь);
					изменениеДанных("КоличествоПопыток", количествоПопыток);
					Сообщить("Ошибка! Пользователь заблокирован; если Вы являетесь владельцем данной учётной записи, обратитесь к администратору.");
				Иначе
					// Вызов процедур:
					изменениеДанных("КоличествоПопыток", количествоПопыток);
					Сообщить("Ошибка! Логин или пароль не найдены.");
				КонецЕсли;
				
				Возврат Неопределено;
			КонецЕсли;
		Иначе
			// Вызов процедур:
			Сообщить("Ошибка! Пользователь заблокирован; если Вы являетесь владельцем данной учётной записи, обратитесь к администратору.");
			
			Возврат Неопределено;
		КонецЕсли;
	Иначе
		// Вызов процедур:
		Сообщить("Ошибка! Логин или пароль не найдены.");
		
		Возврат Неопределено;
	КонецЕсли;
КонецФункции

&НаСервере
Процедура изменениеДанных(параметр, значение)
	// Объекты:
	найденныйПользователь = Пользователь.ПолучитьОбъект();
	найденныйПользователь[параметр] = значение;
	найденныйПользователь.Записать();
КонецПроцедуры

&НаКлиенте
Процедура [Вход](Команда)
	// Объекты:
	роль = ВойтиНаСервере();
	
	// Условные конструкции:	
	Если роль <> Неопределено Тогда
		// Проверка первой авторизации [Условная конструкция]:
		Если НЕ ЗначениеЗаполнено(возвратЗначения("ДатаВхода")) Тогда
			// Вызов процедур:
			ОткрытьФорму("ОбщаяФорма.ФормаСменыПароля", Новый Структура("Пользователь", Пользователь));
			
			// Объекты:
			ЭтаФорма.Закрыть();
			
			Возврат;
		КонецЕсли;
		
		// Проверка роли [Условная конструкция]:
		Если роль = ПредопределенноеЗначение("Перечисление.Роли.Администратор") Тогда
			// Вызов процедур:
			ОткрытьФорму("Справочник.Пользователи.ФормаСписка");
			Сообщить("Успешная авторизация!");
		ИначеЕсли роль = ПредопределенноеЗначение("Перечисление.Роли.Пользователь") Тогда
			// Вызов процедур:
			ОткрытьФорму("ОбщаяФорма.ФормаПользователя");
			Сообщить("Успешная авторизация!");
		КонецЕсли;
	КонецЕсли;
КонецПроцедуры

&НаСервере
Функция возвратЗначения(значение)
	Возврат Пользователь[значение];
КонецФункции
```

### Общий синтаксис — форма смены пароля (нестандартные реквизиты: Роль — ПеречислениеСсылка.Роли; параметры: Пользователь — СправочникСсылка.Пользователи)
```1C

&НаСервере
Функция ИзменитьПарольНаСервере() Экспорт
	Если ТекущийПароль = Параметры.Пользователь.Пароль И НовыйПароль = ПроверкаПароля Тогда
		// Объекты:
		пользователь = Параметры.Пользователь.ПолучитьОбъект();
		пользователь.Пароль = НовыйПароль;
		пользователь.ДатаВхода = ТекущаяДата();
		пользователь.Записать();
		
		Возврат Истина;
	Иначе
		// Вызов процедур:
		Сообщить("Ошибка! Пароли не совпадают.");
		
		Возврат Ложь;
	КонецЕсли;
КонецФункции

&НаКлиенте
Процедура ИзменитьПароль(Команда)
	// Объекты:
```
